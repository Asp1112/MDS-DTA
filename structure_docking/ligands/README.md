# Docking ligands

* `4_Aminophenol.pdbqt` — p-aminophenol ligand (protonated at pH 7.4),
  prepared for AutoDock Vina.
* `acetyl_CoA.pdbqt` — acetyl-CoA ligand referenced by the committed Vina
  config files. The original input file is not available in this workspace;
  re-prepare it from the acetyl-CoA structure (e.g. with AutoDockTools /
  Meeko) before re-running the docking commands. The committed Vina outputs
  (`.out.pdbqt`) and logs do not require this file.
