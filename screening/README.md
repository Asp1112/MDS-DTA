# Screening scores and candidate lists

* `screening_scores_10026.csv` — original MDS screening scores of the
  candidate library.
* `library_ranking_10026.csv` — re-scored ranking of the 8,625 unique
  sequences (columns `crc`, `y_pred`, `new_y_pred`, `new_rank`).
* `library_ranking_with_metadata_10026.csv` — the ranking merged with the
  10,026-record library metadata (one row per library record; records sharing
  a sequence share a rank).
* `top100_library_ranking.csv` / `top300_library_ranking.csv` — Top-100 /
  Top-300 lists generated by `make_topk_lists.py` (100 / 300 unique
  sequences; row counts can exceed the rank cutoff because multiple library
  records map to the same sequence).
* `final_20candidates_ranking.csv` — final ranks and scores of the 20
  experimentally tested candidates (10 from MDS Top-100 and 10 from ranks
  101–300).
* `scripts/` — task-dataset construction, training, scoring and verification
  scripts (original 1,067-sample version and the final reconstructed version).
