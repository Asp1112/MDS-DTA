# Reconstruction experiment archive (2026-08-25)

The files in this folder are outputs of a strict-constraint reconstruction
experiment performed on 2026-08-25 (a rebuilt 1,067-sample task dataset with
soft labels, high-identity homolog anchoring, and a re-trained task model).
They are **not** the screening results reported in the manuscript.

The manuscript screening results are:

* original MDS scores of the candidate library: `../screening_scores_10026.csv`
* Top-100 / Top-300 lists: `../top100_library_ranking.csv`,
  `../top300_library_ranking.csv`
* the 20 experimentally tested candidates: `../final_20candidates_ranking.csv`

This archive is kept for transparency and reproducibility of the
reconstruction validation; it should not be cited as the paper's screening
output.
