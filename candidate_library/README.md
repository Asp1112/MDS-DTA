# Candidate library and screening scores

* `candidate_library_metadata_10026.csv` — the 10,026-record candidate
  library with the original MDS scores (`smiles`, `protein_sequence`,
  `y_pred`).
* `candidate_Top_100.csv` — the Top-100 ranked candidates used for the
  experimental screening.
* `initial_candidate_library_10026.csv` — the candidate library sequences
  before scoring.

The 20 experimentally tested candidates and their manuscript-reported ranks
and scores are listed in `structure_docking/SUMMARY.xlsx`.
