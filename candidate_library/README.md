# 10,026-sequence candidate library

* `candidate_library_metadata_10026.csv` — all 10,026 candidate records with
  sequence (CRC64), UniProt accessions, taxonomy, domain annotations and
  catalytic-motif proxies. This is the exact library used for the MDS
  screening application.
* `initial_candidate_library_10026.csv` — the original candidate-sequence
  pool before metadata merge.

The final MDS scores of these records are in `screening/`.
