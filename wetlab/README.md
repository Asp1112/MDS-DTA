# Wet-lab data

* `Enzyme kinetics.opju`, `HPLC.opju`, `Raw data.opju`, `titer.opju` —
  Origin project files with the raw experimental data (enzyme kinetics,
  HPLC quantification, fermentation titers).
* `HPLC_data.xlsx` — HPLC calibration, method validation (LOD/LOQ), recovery
  and control experiments.
* `kinetics_raw_data.xlsx` — raw initial rates, Michaelis–Menten fits,
  kinetic constants (Km, Vmax, kcat) and residuals for the active
  candidates.
